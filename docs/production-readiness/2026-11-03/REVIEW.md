## Findings ledger

- **F01 — confirmed static; high conditional on exposed, keyed served mode.** [server.ts:11–12](https://github.com/knarayanareddy/myjevuses/blob/12994d215b10016c27a9ecb7ea36fca7f64b6efc/server.ts#L11-L12) caps JSON at `2mb`; [server.ts:22–42](https://github.com/knarayanareddy/myjevuses/blob/12994d215b10016c27a9ecb7ea36fca7f64b6efc/server.ts#L22-L42) clips fields to `20_000` characters but calls `useCase.run` without route-level authentication or rate limiting and returns `error.message`. [server.ts:59–62](https://github.com/knarayanareddy/myjevuses/blob/12994d215b10016c27a9ecb7ea36fca7f64b6efc/server.ts#L59-L62) listens on `0.0.0.0`. An accessible paid-key deployment could incur unbounded usage or reveal exception details; actual exposure and external controls are unknown. Restrict access, enforce budgets and redact errors before such deployment.
- **F02 — confirmed static build-path mismatch; medium drift risk.** [package.json:9–16](https://github.com/knarayanareddy/myjevuses/blob/12994d215b10016c27a9ecb7ea36fca7f64b6efc/package.json#L9-L16) runs `index:repo` for `build:pages`, while [pages.yml:41–50](https://github.com/knarayanareddy/myjevuses/blob/12994d215b10016c27a9ecb7ea36fca7f64b6efc/.github/workflows/pages.yml#L41-L50) invokes `npx vite build` directly. The [index:1–6](https://github.com/knarayanareddy/myjevuses/blob/12994d215b10016c27a9ecb7ea36fca7f64b6efc/src/data/repo-index.ts#L1-L6) says it is generated from `src/` and committed for Pages. Staleness is possible, not demonstrated; add a regeneration comparison.
- **F03 — historical CI, informational.** A [Pages run](https://github.com/knarayanareddy/myjevuses/actions/runs/41442101875) succeeded at the pinned SHA; an earlier [failed run](https://github.com/knarayanareddy/myjevuses/actions/runs/41441389710) used `97a35e649d1429466dd50873dce0fd680f5281d3`. [pages.yml:58–78](https://github.com/knarayanareddy/myjevuses/blob/12994d215b10016c27a9ecb7ea36fca7f64b6efc/.github/workflows/pages.yml#L58-L78) sets `enabled=false` if the Pages check fails and can skip deployment. A successful workflow alone does not establish publication; logs and live site were not checked.
- **F04 — confirmed static adapter gap; medium conditional risk.** [typesafe.ts:87–117](https://github.com/knarayanareddy/myjevuses/blob/12994d215b10016c27a9ecb7ea36fca7f64b6efc/src/engine/typesafe.ts#L87-L117) maps SDK answers with `Number(...)` and falls back to `String(raw.choice)` when a label is unmapped, without visible finiteness, range or option-membership checks in that mapping. Malformed or unexpected provider output could propagate into a decision; no malformed response or downstream effect was reproduced. Validate against requested questions and fail visibly rather than fabricate a valid answer.
- **F05 — confirmed static status limitation; low.** [provider.ts:28–41](https://github.com/knarayanareddy/myjevuses/blob/12994d215b10016c27a9ecb7ea36fca7f64b6efc/src/engine/provider.ts#L28-L41) returns `live: true` when a key is present, and [App.tsx:36–39](https://github.com/knarayanareddy/myjevuses/blob/12994d215b10016c27a9ecb7ea36fca7f64b6efc/src/ui/App.tsx#L36-L39) displays `live jev`. This indicates configuration, not successful authentication or connectivity; distinguish configured, verified and failed states.

## Five-discipline assessment

**Correctness/code review.** F04 matters because the shared result shape does not itself prove the live adapter honors the question's answer space. The README explicitly warns that hostile state can shift classification and recommends an escape option ([README:79–86](https://github.com/knarayanareddy/myjevuses/blob/12994d215b10016c27a9ecb7ea36fca7f64b6efc/README.md#L79-L86)); applicability to individual cases was not audited. Vendor cost, latency and model-quality claims are not independently verified.

**Automation/testing.** [engine.test.ts:32–49](https://github.com/knarayanareddy/myjevuses/blob/12994d215b10016c27a9ecb7ea36fca7f64b6efc/tests/engine.test.ts#L32-L49) asserts a local choice distribution; [usecases.test.ts:7–16](https://github.com/knarayanareddy/myjevuses/blob/12994d215b10016c27a9ecb7ea36fca7f64b6efc/tests/usecases.test.ts#L7-L16) and [31–59](https://github.com/knarayanareddy/myjevuses/blob/12994d215b10016c27a9ecb7ea36fca7f64b6efc/tests/usecases.test.ts#L31-L59) exercise local defaults and presets. These are useful, not evidence of live SDK or HTTP-boundary correctness. Workflow runs `npm test`, but sampled steps do not run the manifest's `typecheck` script.

**DevOps/operations.** F02/F03 separate reproducible build, enabled Pages and actual publication. Workflow actions use version tags rather than immutable commit pins ([pages.yml:32–38](https://github.com/knarayanareddy/myjevuses/blob/12994d215b10016c27a9ecb7ea36fca7f64b6efc/.github/workflows/pages.yml#L32-L38), [70–86](https://github.com/knarayanareddy/myjevuses/blob/12994d215b10016c27a9ecb7ea36fca7f64b6efc/.github/workflows/pages.yml#L70-L86)); dependency and action integrity remain unverified, not a demonstrated compromise.

**OWASP/security.** F01 concerns authorization, resource consumption and error disclosure. Injection into user-supplied model state, secret custody, dependency integrity, input retention and provider-side processing are unverified risks. The server echoes accepted input in its result ([server.ts:29–39](https://github.com/knarayanareddy/myjevuses/blob/12994d215b10016c27a9ecb7ea36fca7f64b6efc/server.ts#L29-L39)); no storage, leakage or malicious execution was established. Use synthetic data until data flows and logs are reviewed.

**UI/UX/accessibility.** Mode labels exist, and [App.tsx:47–58](https://github.com/knarayanareddy/myjevuses/blob/12994d215b10016c27a9ecb7ea36fca7f64b6efc/src/ui/App.tsx#L47-L58) shows loading, error and route states. Keyboard, screen-reader announcements, contrast, responsive behavior and F05 failure messaging require browser checks; no accessibility defect is asserted from this sample.
